Skúškové otázky:

* SO(3) - Rotations - properties, different representations, applying rotations to points
* Affine and Euclidean transformations in 2D and 3D - geometrical meaning, transformation matrices, implementation
* Pinhole Camera Model - geometrical meaning/derivation, mathematical formulation, intrinsic and extrinsic camera parameters, including distortions
* Homography - projection of planes, mathematical derivation, transformation under fixed camera center, properties
* Homography estimation - direct linear transform, RANSAC and non-linear optimization basics
* Vanishing points and lines - geometrical meaning, mathematical derivation, vanishing points at infinity, camera calibration applications
* Epipolar geometry - epipoles, epipolar lines, epipolar plane, geometric derivation of F
* Fundamental Matrix - correspondence conditions, properties, decomposition, F under pure translation
* Essential Matrix - correspondence conditions, relation to F, properties, extracting motion, 5-point algorithm basics
* 8-point algorithm - mathematical derivation, practical implementation
* 7-point algorithm - mathematical derivation, practical implementation
* Triangulation - computation, ambiguities in structure computation, point correspondences
* Stereo - rectification, disparity maps, technical approaches, depth measurement error
* Incremental SfM - initialization, absolute pose estimation, base SfM algorithm
* Bundle Adjustment - problem definition, gradient based numerical optimization, use within SfM
* RANSAC - basic algorithm, expected number of iterations, RANSAC modifications
* Pointcloud Processing - representations, basic processing operations, ICP
* Deep Learning on Pointclouds - desired properties, PointNet, other approaches
